Checking setup. The Vercel deployment includes the website and API endpoints.
Relay servers should only forward to domains explicitly allowed by their owner. The default is example.com. To allow another site you control or may access, add its hostname to ALLOWED_HOSTS in Vercel Project Settings → Environment Variables, separated by commas, then redeploy. Use *.example.com for subdomains and add example.com too if you need the root domain. This is not a bypass for network or website access restrictions.
